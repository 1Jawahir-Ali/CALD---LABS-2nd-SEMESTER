<h3>📘Overview</h3>
This repository contains my <b>Computer Architecture & Logic Design (CALD)</b> laboratory work for the 2nd semester, including both **regular labs** and an **Open Ended Lab Project**.  
<h3>📂Repository Structure</h3>
<h3>Lab Highlights</h3>
<h3>Labs of CA&LD:</h3>
  Step-by-step experiments covering:
  1. Basic logic gates and truth tables  
  2. Combinational circuits (adders, multiplexers, decoders, etc.)  
  3. Sequential circuits (flip-flops, counters, shift registers)  
  4. Arithmetic units (ALU design, adders, subtractors)  
  5. Memory modules (RAM/ROM, registers, addressing)  

<h3>CALD Open Ended Lab:</h3>  
  A custom project applying CALD concepts to design and implement a **real-world inspired digital logic system**, with design files and a detailed report.
