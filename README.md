<h3>About Repository</h3>
<h4>📘Overview</h4>
This repository contains my <b>Computer Architecture & Logic Design (CALD)</b> laboratory work for the 2nd semester, including both **regular labs** and an **Open Ended Lab Project**.  
<h4>📂Repository Structure</h4>
  Step-by-step experiments covering:<br>
  1. Basic logic gates and truth tables<br>  
  2. Combinational circuits (adders, multiplexers, decoders, etc.)<br>  
  3. Sequential circuits (flip-flops, counters, shift registers)<br>  
  4. Arithmetic units (ALU design, adders, subtractors)<br>  
  5. Memory modules (RAM/ROM, registers, addressing)<br>
